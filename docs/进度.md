根据比赛资料搭建 Ubuntu 本机开发环境，完成可复现的基础 MuJoCo 仿真，通过私有 GitHub 仓库跨设备共享代码、结果与决策。PPT 和交付视频由 Windows 或其他组员后续完成。

- 验证 EGL 截图/动画输出，并实际打开 GLFW 桌面查看窗口后自动关闭。
- 固定依赖版本，保存结果 JSON、轨迹 CSV 和可见截图。

## 基础验证的具体设置

- 物理时间步 0.002s，控制周期 0.02s，每周期 10 个物理步。
- Newton 求解器，elliptic 摩擦锥，iterations=50、ls_iterations=10、impratio=100。
- 目标关节角为 home 姿态，策略动作为零；PD kp=40、kd=2，在每个物理步重算力矩并按执行器限制裁剪。
- 按 actuator_trnid 映射关节位置和速度，不能把关节数组顺序直接当电机顺序。
- 默认 home 的 ctrl 是角度值，而电机输入是力矩；重置后必须清零 ctrl。
- 当前脚本仅验证姿态保持，不实现行走、189 维观测、RGB/LiDAR 任务接口或正式策略控制器。

## 已发现并解决的问题

1. 完整赛场 home keyframe 位于 (0,0,0.27)，与南/西边界墙重叠。未经处理的站立测试在 3.15 仿真秒发生 QACC 数值警告。
   - 仅在内存中的测试模型将出生位置设置为 (1,1,0.30)，这是本地无碰撞验证点，不是正式赛事起点。
   - 重置时检查较大初始穿透；原始 MJB 和哈希保持不变。
2. 赛场地形放在几何组 3，默认渲染隐藏该组，最初画面只显示机器人。
   - 本地调试查看启用组 3，展示物理碰撞地形；不代表正式 RGB 传感器渲染合同。
3. XML 默认求解器迭代数与指南不同。
   - 本地模型统一设置指南基线；不修改资源 XML。

## 2026-11-16 操控反馈与基础运动阶段

已完成新目标：明确力矩控制与 52 维原始传感器反馈，实现键盘操控、关节偏移探测、基础前进/后退/左右转向，并同步记录前视相机与反馈。

- 新增 `robot_control.py`：平地环境、随体相机、手写步态、PD 力矩与反馈读取。
- 新增 `control_feedback.py`：W/S/A/D/空格/Q 操控，或自动序列；50Hz 反馈和 10Hz 图像按整数仿真纳秒对齐。
- 新增 `validate_feedback.py`：校验反馈、相机哈希与时间戳，并验收运动方向和关节响应。
- 6 个完整带相机会话全部通过，共 746 帧、3706 条反馈。24 秒连续动作无跌倒；完整数据在 `输出/操控反馈/`。
- GitHub 同步源代码、说明、验证摘要和相机/反馈摘样；完整原始数据本机保留。

本阶段用 kp=80 的本地平地步态，尚未接入正式 kp=40/动作缩放/观测接口；转向有平移，前后速度不对称。旧文中的“尚未实现行走”仅描述上一阶段，当前具体能力与边界以 [操控与传感器](操控与传感器.md) 为准。

## 完整公开赛场操控接入

操控程序新增 `--scene course`，直接加载原始完整 MJB。启用地形显示，并为没有相机槽位的二进制模型实现随体虚拟前视相机，继续保留时间戳同步记录。

6 秒短距离前进实测 +0.337m、61 帧/301 条反馈，对齐和运动验证通过；键盘查看窗口启动/关闭通过。坡道和乱石通行尚未验证，不能把平整区结果扩展为完整路线通过。


## 方向键与速度更新

按用户反馈，取消 WASD，使用 ↑/↓/←/→。新增专用 GLFW 操控窗口，避免 Simulate 的快捷键改变画面；空格停止、Q 退出，左键拖动/滚轮调整视角。默认步幅速度倍率为 2，支持 `--speed 1` 恢复旧速度。

新版 10 秒平地前进 2.319m，后退 3.415m，左右转角约 ±2.5rad；24 秒连续动作无跌倒。当前速度仍是本地实验步态参数，不代表正式比赛控制接口或复杂地形通行能力。

## 操控窗口隐藏修复

用户反馈新窗口不可见。定位到 MuJoCo 离屏相机的 GLFW 上下文会将全局窗口提示 VISIBLE 设为 0，专用操控窗口继承后被隐藏。修复为创建前恢复默认提示、显式启用 VISIBLE，并显示和聚焦窗口。

按真实初始化顺序（先相机、后操控窗口）复测：VISIBLE=1、FOCUSED=1，窗口尺寸 1000×720，正常创建和关闭。先前仅检查窗口生命周期，未检查可见属性，现已加入运行时可见性检查。

## 双窗口相机预览与初始左转 90°

新增独立 CameraViewer，10Hz 显示记录器的同一 RGB 帧及仿真时间；两个窗口都能接收方向键、停止和退出。默认初始朝向左转 90°，支持 --yaw-deg 自定义。运动方向校验按初始机体前向投影。

双窗口可见性检查通过；读回相机窗口像素，与缩放后的记录帧逐像素一致。赛场默认新朝向下 4 秒前进 +Y 约 0.627m，41 帧/201 条反馈校验通过。
