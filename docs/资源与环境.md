训练 ZIP：`training-package-v8.zip`。

SHA-256：`d42166b859232e2826533945512e298b6ec3640f4c68fb40138e732089b33824`。

解压后应存在：

```text
资源/训练包/robotics-bench-go2-competition-training-resources/
  MANIFEST.json
  SHA256SUMS
  robot/go2/physics/go2.xml
```

ZIP 与交接记录一致且内部校验通过；尚未独立核对赛事页面最新发布值。平台正式任务版本、起点、传感器和提交结构仍需队长核实。

原始 PDF、视频、场景及网格不上传 GitHub。包内 NOTICE 明确汇总不扩大源资产的再分发许可，跨设备请从有权限的赛事资料渠道取得原包。

## 本机环境

- Ubuntu 22.04.5 LTS，x86_64。
- Python 3.12.16，安装在项目 `.tools/`；虚拟环境 `.venv/`。
- MuJoCo 3.17.0，Pillow 13.0.0，NumPy 2.5.5；完整版本见 requirements-lock.txt。
- NVIDIA RTX 4080 Laptop，12282 MiB 显存，驱动 580.178.04。
- EGL 离屏渲染及 GLFW 桌面查看器均通过。
- MuJoCo 标准物理步进在 CPU 上运行；当前 NVIDIA GPU 用于画面渲染。
- 没有安装 PyTorch、ONNX Runtime 或训练环境，它们不属于此次基础仿真所需依赖。后续接入策略时再按赛事要求安装，ONNX Runtime 基线为 1.31.1 CPU。

本次仿真使用 NumPy 2.5.5，不是入门训练 PDF 示例中的 2.5.4；当前未执行该训练教程，不宣称其环境已经复现。后续训练需独立核对依赖版本。

参考接口：[MuJoCo 3.17.0 Python 文档](https://mujoco.readthedocs.io/en/3.17.0/python.html)。
